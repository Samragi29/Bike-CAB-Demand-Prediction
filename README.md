# Bike-CAB Demand Prediction Using Machine Learning

## Project Overview
This project uses Machine Learning to predict bike/cab demand based on factors such as time, weather, temperature, humidity, and working days. It performs both demand classification and ride count prediction.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Algorithms Implemented
- Linear Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Decision Tree

## Project Features
- Data preprocessing and analysis
- Data visualization
- Demand classification (Low, Medium, High)
- Ride count prediction
- Model evaluation and comparison

## Model Results

| Model | Performance |
|---|---:|
| KNN Classifier | 75% Accuracy |
| Naive Bayes | 65% Accuracy |
| Decision Tree Classifier | 90.7% Accuracy |
| Decision Tree Regressor | 0.897 R² Score |

## How to Run
1. Download or clone this repository.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

3. Run the Python project:

```bash
python bike_demand_project.py
```

## Objective
The main objective is to analyze transportation demand patterns and help improve vehicle availability, resource allocation, and demand planning.
